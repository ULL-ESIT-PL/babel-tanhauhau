DefaultObject

DefaultObject

Objeto envoltorio que permite definir valores por defecto dinámicos cuando se accede a claves no existentes o que no cumplen un criterio personalizado. Utiliza un `Proxy` para interceptar operaciones sobre propiedades del objeto base.
